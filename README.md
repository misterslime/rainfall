Cool cellular automata I made using C++ and SDL3 that resembles rainfall.

To build:
1. Clone the repo using `git clone https://github.com/misterslime/rainfall.git`.
2. Build the SDL submodule in the **Release x64** configuration.
3. Build the rainfall project and run.

Ensure that `SDL.dll` is located in the same directory as the .exe if running outside your IDE.

I used this tutorial to make it:
https://solhsa.com/gp2/ch01.html
